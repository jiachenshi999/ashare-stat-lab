## 八、尚未解决的问题

1. **东方财富指数接口限频**：`index_zh_hist_em` 触发 Push2RateLimitError，未接入；新浪源已满足 P0 需求。
2. **MCP `get_time_info` 已损坏**（`tool_trade_date_hist_sina` 更名），本项目不依赖它，改用行情首末日期。
3. **无头软件渲染下 P0-2 较慢**：8767 点散点在 headless `--disable-gpu` 软件渲染下需约 1 分钟；真实浏览器（GPU 加速）不受影响（Node 侧 renderP02 纯计算仅 322ms）。
4. **P1/P2 历史截面数据缺失**：本机数据源无可靠的历史涨跌家数/市值/退市股完整截面，市场广度等模块暂不实现，避免幸存者偏差。
