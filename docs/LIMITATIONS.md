# 已知限制与数据边界（docs/LIMITATIONS.md）

## 1. 数据来源与口径

- 指数历史数据来自**新浪财经**（`index_zh_daily_sina`，未复权），腾讯（`index_zh_daily_tx`，前复权）为备用源。新浪接口文档未提供官方书面单位说明，`volume` 按"股"记录，`amount` 新浪源缺失（仅腾讯源提供）。
- 东方财富指数接口（`index_zh_hist_em`）当前对本机 IP **限频**（Push2RateLimitError），本版未使用；后续若限频解除可作交叉校验源。
- 指数历史起点可能与官方"基日/发布日"不同：部分指数（如沪深300、中证1000）在新浪/东方财富提供**回测填充**的更长序列。界面如实显示数据源实际首末日期，不保证与指数公司官方发布日完全一致。
- **价格收益不含现金分红**。指数收盘点位是"价格指数"，未计入分红再投资；不可当作某个可交易产品扣费后的实际回报。

## 2. 统计口径边界

- 所有频率/分位均为**样本经验频率**，不是未来概率；样本越小越不稳定。
- 早期（1990–1996）市场制度差异大（放开股价、涨跌停制度演变），单日 +105.27%（1992-05-21）、-16.39%（1995-05-23）等为真实事件，会显著抬高偏度/峰度。全历史口径下这些指标受早期样本主导，需分时期观察。
- 滚动持有期收益高度重叠相关，非独立实验。
- 最大回撤以**收盘价**计算，盘中极值（如 2007-10-16 盘中 6124.04）与收盘极值（收盘 6092.06）不同，本页统一用收盘价并已注明。

## 3. 尚未实现（P1/P2 阶段，后续扩展）

- **市场广度（P1-5）**：历史逐日上涨/下跌家数、等权/市值加权市场收益、退市股完整历史——本机数据源不提供可靠历史截面，暂不实现（避免幸存者偏差）。
- **公司规模与行业结构（P1-6）**：当前/最近收盘日截面（公司数量、市值分布、Gini、申万行业）尚未接入。
- **流动性/成交额（P1-7）**：指数成分股成交额历史序列尚未接入。
- **估值/盈利/分红（P2-8）**：同口径历史 PE/PB/股息率、全收益指数尚未接入。
- **行业轮动/风格/相关性（P2-9）**：申万行业指数、大小盘相对强弱、滚动相关性尚未接入。
- **事件条件统计**：尚未实现。

以上模块按《开发总指令》P1/P2 阶段逐步推进；缺失时页面会明确标注"数据受限/未实现"，不以模拟数据填充。

## 4. 运行边界

- 服务仅绑定 `127.0.0.1`，不开放局域网/公网，无需账号，不调用付费 API。
- 数据更新（`update_data.bat`）为**全量重拉**（数据量小，简单可靠）；增量补取留待后续。更新失败不破坏旧数据（写入为新文件）。
- 后端为纯标准库实现，断网时仍可读取已缓存数据并正常出图；仅"更新数据"需要联网。
- 前端统计由浏览器即时重算（已与后端 Python 交叉验证），首次加载约 1.5MB JSON。
