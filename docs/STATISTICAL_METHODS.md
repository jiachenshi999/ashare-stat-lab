# 统计方法与口径（docs/STATISTICAL_METHODS.md）

> 本文档定义所有统计口径，前端 `app.js` 与后端 `backend/analytics.py` 实现完全一致，并已通过单元测试交叉验证（tests/test_statistics.py 与 tests/smoke_js.js）。

## 1. 通用定义

| 量 | 定义 | 说明 |
|----|------|------|
| 日简单收益 | `r_t = (Close_t / Close_{t-1} - 1) × 100`，单位 % | 第一笔无前值不计入；按实际交易日序列；价格收益不含现金分红 |
| 对数收益（可选） | `ln(Close_t / Close_{t-1}) × 100` | 默认不启用，严禁与简单收益混用 |
| 样本标准差 | `std(·, ddof=1)` | 样本标准差 |
| 年化波动率 | `std(小数日收益, ddof=1) × √252` | 用**未乘100的小数收益**计算，结果以 % 展示；252 仅为交易日年化约定 |
| 经验左侧百分位 | `F_n(x) = #{r_i ≤ x} / N` | **含相等值**；另有严格小于的比例供参考 |
| 负向尾部频率 | `#{r_i ≤ -a} / N` | `a ≥ 0` |
| 双向大幅波动 | `#{|r_i| ≥ a} / N` | `a ≥ 0`，与带符号分位严格区分 |
| 分位数 | 线性插值（等价 numpy `percentile` method='linear'） | 用于 P1/P5/…/P99 描述性分位 |
| 偏度 | Fisher–Pearson 标准化三阶矩，偏置校正 | 等价 scipy `skew(bias=False)` |
| 超额峰度 | 偏置校正 | 等价 scipy `kurtosis(bias=False)` |

## 2. 回撤

- 回撤序列：`DD_t = Close_t / cummax(Close_{≤t}) - 1`（按历史累计峰值）。
- 回撤事件：一个**最大水下区间**（DD < 0 的连续段）。事件字段：
  - `peak_date/value`：区间开始前的峰值日（最近一次创新高的收盘）；
  - `trough_date/value`：区间内最低收盘；
  - `recovery_date`：收盘首次 ≥ 峰值日的日期；
  - `down_duration`：峰值日 → 谷底日 的交易日数；
  - `recovery_duration`：谷底日 → 恢复日 的交易日数；
  - `total_duration`：峰值日 → 恢复日 的交易日数；
  - `recovered`：是否已恢复；**未恢复事件为右删失**（recovery_* 为 null），不以"今天"冒充恢复日。
- 整体最大回撤：全样本 `DD_t` 的最小值及其峰值日/谷底日。
- 滚动最大回撤（窗口 w）：对每个交易日 t，取 `[t-w+1, t]` 区间内的最大回撤。
- 最长连续未创新高：DD < 0 的最长连续交易日段。
- 处于回撤阈值以下的比例：`#{DD_t ≤ -a%} / N`（a ∈ {5,10,20}）。

## 3. 持有期收益

- `R_(t,h) = Close_{t+h} / Close_t - 1`（用**交易日序号** h，禁止用日历天代替）。
- 只有存在第 `t+h` 个实际交易日才纳入；样本量随 h 增大而减少。
- 汇总：盈利比例、亏损超过 5/10/20% 比例、中位数、P5/P95、均值、最差/最好。
- **重叠窗口警示**：连续滚动持有期收益高度相关，非独立投资实验；盈利比例只是历史滚动起点的频率，不代表未来盈利概率。

## 4. 日期过滤约定

- "近 N 年" = 截至最后观察日往前 N 个**自然年**（界面显示实际样本 N）。
- 日收益**先用完整历史计算，再按日期取区间**，避免区间起始日收益因"缺上一日"而丢失（起始日收益仍使用区间外的上一收盘，属规范允许的边界约定）。
- 切换指数/区间后，所有分位、波动率、尾部频率、回撤、持有期统计**在同一批有效日期上重新计算**。

## 5. 测试样例（人工数据，与《开发总指令》5.2 一致）

- 价格 `[100,90,80,100,110]` → 收益 `[-10%, -11.11%, +25%, +10%]`；最大回撤 `-20%`（峰值 100 → 谷底 80，恢复到 100）。
- 日收益 `[-3,-1,0,1,2]`（%）→ `F(-1)=2/5=40%`，`P(R≤-2)=1/5=20%`，`P(|R|≥2)=2/5=40%`。
- 单位转换：1 手 = 100 股；1 万元 = 10^4 元；1 亿元 = 10^8 元。

## 6. 样本量阈值

| 指标 | 阈值 | 低于阈值行为 |
|------|------|--------------|
| 总体分布 | N ≥ 100 | 标注"样本不足" |
| 滚动指标 | N ≥ 250 | 标注"样本不足" |
| 极端条件事件 / CVaR 尾部 | N ≥ 30 | 不展示或标注"样本不足" |

## 7. 解释边界

- 所有历史发生频率都是**给定样本中的经验频率**，不是未来风险概率。
- 非正态性/肥尾/波动聚集结论以图表与数值证据支撑；不用"六西格玛不可能事件"式话术。
- 指数价格收益 ≠ 可交易产品扣费后的收益（未计分红、ETF 跟踪误差、交易费用、印花税、滑点）。
- 早期（1990 年代初）制度差异（无涨跌停、放开股价）导致单日 ±100%/±16% 等极端值，属真实事件，保留但需分时期观察。
