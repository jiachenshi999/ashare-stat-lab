# V1.2 增补说明（2026-11-22）

> 按用户反馈迭代：UI 修复、多研究对象、数据多来源、GitHub 托管、阶段 2/3。

## 一、已修复的前端问题（对应标注截图）

1. **模板变量泄漏**：KPI 卡片中 `$ {rangeLabel()}` 等未插值文本已修正；`tests/render_check.js` 对全部 8 个模块 × 单/多对象校验通过（无 `${` 泄漏、无渲染异常）。
2. **页面布局**：内容区最大宽度 1420px 居中、内边距与卡片间距加大，不再贴满浏览器边缘。
3. **研究对象多选**：顶部改为复选框下拉，可同时勾选全部指数；概览趋势、ECDF、价格走势、回撤水下图均支持多曲线 + 图例。
4. **ECDF 语义修正**：新增"只看下跌日 / 只看上涨日"的序列内百分位（-1.5% 在下跌序列的位置、+1.5% 在上涨序列的位置）。
5. **空图表修复**：
   - 极端 TOP20 在当前区间事件不足时**回退全历史**并提示；
   - 年份分布改为真正的**热力图**（年份 × 幅度分桶）；
   - 滚动波动率**窗口自适应**（短区间不再空白），过短时提示样本不足；
   - 左尾图改为**经验 vs 正态柱状 + 倍数线**，并给出通俗读法；
   - **VaR/CVaR 修正**：此前误用第 95 百分位（上涨侧），现改为下尾（最差 5%/1%）并附解释。
6. **散点图交互**：日收益时序散点支持 **x / y 双向缩放与滑动**。
7. **极端日原因**：新增 `data/events.json` 历史事件库，极端 TOP20 每行列出最多 3 条可能原因；未收录的如实标注"未收录"，不臆造。
8. **逐年箱线**：限定最近 15 年、高度缩小；日期查询面板新增 ECDF 定位配图。

**实测发现**：最近交易日上证指数仅 -1.22%，但 **93.8% 个股下跌、个股涨跌幅中位数 -5.07%**；腾讯与新浪双源一致。这正是"指数上涨但多数股票下跌"的结构性行情证据。

## 三、多数据来源（抗单源限频）

指数历史行情按 **新浪 → 中证指数公司（官方）→ 腾讯** 自动回退：
- 新浪 `index_zh_daily_sina`（主源，上证指数自 1990-12-19 全历史 8768 行）
- 中证指数公司 `index_hist_csindex`（官方，覆盖上证指数/沪深300/上证50/中证500/中证1000）
- 腾讯 `index_zh_daily_tx`（前复权，末级备用）

**数据不退化保护**：若某次抓取行数明显少于已有数据（<95%），保留旧数据并告警，绝不使用降级短序列覆盖完整历史（已在实际回退中验证生效）。

> 说明：本次未新增 MCP 服务器（东方财富限频不影响本项目，因为已在 akshare 层实现三源回退）；如需 MCP 生态扩展，`akshare-mcp`（PyPI）可将全部 akshare 接口暴露为 MCP 工具。
