# A股市场统计认知实验室（A-Share Market Statistical Laboratory）

用真实历史数据与严谨、可交互的统计图，认识中国 A 股市场的波动、极端风险、回撤与长期持有结果。

- 🌐 **在线访问（GitHub Pages）**：<https://jiachenshi999.github.io/ashare-stat-lab/>
- 💻 **本地运行**：见下方"快速开始"
- 📦 **源码仓库**：<https://github.com/jiachenshi999/ashare-stat-lab>

> 本页面不构成任何投资建议；所有数字均为历史样本经验统计，不代表未来概率。

## 一、运行环境

- Windows 10/11，8GB 内存即可。
- 已安装 DeepSeek Harness + AkShare 系 MCP（`china-stock-mcp`，内含 akshare 1.20.65 + Python 3.12.14）。
- 无需 Node.js、无需付费 API Key；数据已本地缓存，断网可看。

## 二、快速开始

1. **更新数据**（需联网）：双击 `update_data.bat`，或 `python update_data.py`。
   抓取 7 个指数真实历史日线 → 规范化 → 统计 → 生成前端静态数据。
2. **启动网页**：双击 `start.bat`，或 `python app.py`，浏览器打开 **http://127.0.0.1:8765**。
3. 更新阶段 2/3 数据：`python backend/stage23.py`（市场广度、成交额、估值、行业）。

## 三、已实现功能

### P0 核心（统计分布与风险）
- **P0-1 每日涨跌分布**：直方图（bin 可调）+ 核密度 + 正态参考；ECDF 与左尾；逐年箱线；**单日极端涨跌 TOP20（含主要原因）**；按交易日查询（**含"只看下跌日/上涨日"序列内百分位**）；对称尾部频率。
- **P0-2 极端事件与尾部**：日收益时序散点（**x/y 双向缩放**，标注极端）；|收益| 年份热力图；滚动年化波动率（窗口自适应）；左尾经验 vs 正态（倍数）；历史 VaR/CVaR（已修正为下尾，附通俗解释）。
- **P0-3 牛熊与回撤**：价格走势（对数轴）+历史峰值；回撤水下图；回撤事件深度-时长散点（右删失）；滚动 1/3 年最大回撤。
- **P0-4 持有期收益**：5/20/60/120/250/500 交易日箱线、盈亏比例、分布直方图、汇总表。

### P1 广度、规模与流动性
- **P1-5/6 市场广度与规模结构（最新截面）**：涨跌幅分布、各板块涨跌家数、市值分组、洛伦兹曲线 + 基尼、Top20 市值、PE/PB 中位数。**已实测：某交易日指数仅跌 1.22%，但 93.8% 个股下跌、中位数 -5.07%**（腾讯/新浪双源一致）。
- **P1-7 成交与流动性**：指数成交额历史、历史分位与滚动 252 日分位、最新/中位数比值（注明"指数成分股成交额≠全市场"）。

### P2 估值与行业
- **P2-8 估值**：指数滚动 PE_TTM 历史 + **5 年滚动分位带（P20/P50/P80）**；**当前 PE 在 5 年 / 10 年 / 全历史中的经验分位**；申万 31 行业当前 PE / PB / **股息率** 截面、**31 行业 PE 截面箱线（含离群行业）**。
- **P2-9 行业轮动与风格**：行业年度收益热力图、**行业相对沪深300 的年度超额收益热力图**、**主要指数累计收益（起点=100）**、**大小盘相对强弱（上证50/中证1000）**、**行业与沪深300 滚动 60 日相关性 + 沪深300 滚动 250 日年化波动率**、行业近 1 年累计收益排名、**重点行业一键筛选**（银行/非银/有色/石油石化/基础化工等）。
- **如实标注的数据缺口**：个股口径的分板块估值分位、行业估值的历史分位、盈利与估值分解、分红全收益指数均未取得可信序列，页内逐条明示"数据不足、不绘制"，不用假数据填充。

### 交互与体验
- **研究对象多选**：可同时勾选多个指数，趋势/ECDF/回撤等图表多曲线叠加并带图例。
- 时间范围（全部/近1/3/5/10年/自定义）× 指数切换，所有统计同步重算。
- 每个模块标注研究对象、起止、N、口径、来源、更新时间，并含"主要发现/容易误读"。
- 涨红跌绿、本地 ECharts、CSV 导出、PNG 下载（P0-1）、离线可读。

## 四、多数据来源（抗单源限频）

指数历史行情按 **新浪 → 中证指数公司（官方）→ 腾讯** 顺序自动回退：
- 新浪 `index_zh_daily_sina`（主源，上证指数自 1990-12-19 全历史）
- 中证指数公司 `index_hist_csindex`（官方源，覆盖上证指数/沪深300/上证50/中证500/中证1000）
- 腾讯 `index_zh_daily_tx`（前复权，末级备用）

另设**数据不退化保护**：若某次抓取行数明显少于已有数据（<95%），保留旧数据并告警，绝不用降级短序列覆盖完整历史。

## 五、目录结构

```
Ashare-Stat-Lab/
├─ start.bat / update_data.bat
├─ app.py                     # 本地服务（纯标准库，127.0.0.1:8765）
├─ config.py                  # 全局配置
├─ update_data.py             # 数据更新入口（含 build_static）
├─ build_static.py            # 生成 frontend/data 静态数据（GitHub Pages 同源）
├─ backend/
│  ├─ data_sources.py         # 新浪→中证官方→腾讯 多源回退
│  ├─ collector.py            # 采集 + 落盘 + 不退化保护
│  ├─ normalize.py            # 字段/单位规范化 + 质量校验
│  ├─ analytics.py            # P0 核心统计
│  ├─ compute.py              # 生成 stats/*.json
│  └─ stage23.py              # P1/P2 数据（广度/成交/估值/行业）
├─ frontend/                  # index.html + styles.css + app.js + assets/ + data/
├─ data/{raw,processed}/ + events.json
├─ tests/                     # 单元测试 + JS 冒烟 + 渲染检查
└─ docs/                      # 审计/数据字典/统计方法/限制/实现报告
```

## 七、数据来源与免责

指数：新浪财经 / 中证指数公司 / 腾讯；市场截面：腾讯/新浪；行业：申万。指数价格收益不含分红；早期市场制度差异导致极端值真实存在。详见 `docs/`。
